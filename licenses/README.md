# Third-party licenses

See [NOTICE](../NOTICE) for the scope of derived material. `sources.json` lists the upstream palette sources and retrieval date. `starship.txt` is the ISC license from Starship v1.24.2; its shipped presets and generated import fixtures are retained under that license.

Original palette revisions were not recorded during development. The upstream license copies here were retrieved during the 2026-11-07 audit; this is disclosed rather than presented as exact historical provenance.

Binary archives additionally contain `dependencies/`, generated from Cargo.lock and Cargo metadata by `scripts/collect-licenses.py`. It contains upstream license files and package names, versions and declared license expressions; local Cargo registry paths are omitted.
