# 0.4.1 release record

Date: 2026-11-07. **Published:** [0.4.1 binary release](https://github.com/WatsonHS/homebrew-tildy/releases/tag/v0.4.1). All four public assets were downloaded anonymously and matched the local SHA-256 values.

## Scope

Blank/whitespace input dismisses stale error status without changing the real command exit code. The change includes compact/full history and plugin regression coverage. No new prompt feature is added.

Source cleanup replaces private development transcripts with public guides, adds MIT and third-party notices, retains runnable fixtures and moves executable examples into scripts. Binary archives include notices for the 52 locked production dependencies across the four release targets.

## Daily use and M6

On 2026-11-07 the maintainer reported several weeks of use and a positive experience. No day-by-day log was supplied, so this records qualitative feedback, not an independently reconstructed 14-day zero-defect run. Independent tester feedback, native Intel platform coverage and the remaining 1.0 support commitment are still open. M5 remains deferred.

## Source publication boundary

The source is published at [WatsonHS/tildy](https://github.com/WatsonHS/tildy), starting with a clean 0.4.1 snapshot and fresh Git history. Historical development commits and personal machine evidence remain private. Builds, tests and packaging run locally; this repository has no hosted CI.

## Publication and remaining scope

The tap's `v0.4.1` tag and formula contain the final archive checksums. Both the Homebrew executable and the maintainer's explicitly configured development executable report 0.4.1. Existing terminals need to be reopened to load the new adapter.

The initial public snapshot includes a per-file SHA-256 manifest and excludes personal trial logs and historical Git objects. Its heuristic hygiene checks found no known personal path/chat-link/credential patterns; this is not a claim of exhaustive secret detection. Historical raw evidence and the original Git bundle remain private.

This closes the patch release and source-cleanup work. It does not declare 1.0, fabricate a daily trial log, or claim native macOS Intel runtime/GUI coverage.
